# 💰 百万美金（Millions of Dollars）在线版

多人同时在线的《百万美金》网页版：整个服务只有**一个房间**，所有人打开同一个网址即可加入。支持 3–8 人（3 人为"一人两角"特殊玩法），中途刷新或断线可自动回到座位。

## 本地运行

```bash
npm install
npm start          # http://localhost:3000
npm test           # 规则逻辑测试
```

## 部署到 Render

1. 在 Render 新建 **Web Service**，连接本仓库（或用仓库里的 `render.yaml` 通过 Blueprint 一键创建）。
2. Runtime 选 Node，Build Command：`npm install`，Start Command：`npm start`。
3. 部署完成后把 `https://xxx.onrender.com` 发给朋友即可。

注意：
- 游戏状态保存在内存里，**只能跑 1 个实例**；服务重启/重新部署会清空当前对局。
- Render 免费实例闲置约 15 分钟会休眠，第一次打开需要等几十秒唤醒。

## 玩法要点

- 第一个进入的人是房主，负责设置与开始游戏；房主断线时由下一位在线玩家代理。
- 每轮：秘密选身份并缴保证金 → 角色牌混洗、藏 1 张公开其余 → 自由谈判（聊天、转账、"付钱换退出"交易、威胁卡偷看）→ 所有仍在本轮的玩家确认"开车"（掉线超过 30 秒的不再等待）→ 自动判定与分赃。
- 带头人每轮顺时针轮换，负责进入下一轮；房主可为迟迟不选的玩家随机选身份，也可以强制开车。
- 游戏开始后新进入的人是旁观者，可以看公开信息。
- 顶部可以随时改名；游戏中任何玩家都可以发起"投票重开"，在线玩家过半同意后本局作废、回到大厅。

## 规则实现中的取舍

规则整理稿缺少第 1 页和牌组明细，以下是自行补充或取舍的地方：

| 问题 | 处理 |
| --- | --- |
| 赃款牌明细 | 每轮随机生成：800–1200 万，1200 万保证金 200 万、800 万保证金 100 万、其余随机；80% 带随机角色奖励图标（见 `game.js` 的 `LOOT_AMOUNTS`） |
| 角色牌 10 选 8 | 线上版每人可从本局所有角色中任选 |
| 唯一的暴徒是否参与分赃 | 规则文字写"退出分赃"，但分赃示例、恶棍能力和"暴徒至少有 200 万可付"的说明都要求暴徒参与分赃。默认**参与**，房主可在大厅关闭 |
| 现金不足交保证金 | 储备现金补足；退还时只退玩家自己实际交的部分 |
| 告密者分赃 | 唯一的告密者取回保证金、点名后正常参与分赃；若没有任何其他角色幸存，则告密者罚 300 万且不分赃（现金不会扣成负数） |
| 付车费/被恶棍拿钱时现金不足 | 最多付到 0，不欠款 |
| 退出者"保持沉默" | 不强制禁言，靠自觉 |
